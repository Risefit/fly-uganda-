# Payment scheme marks

Drop the OFFICIAL logo files here and they appear in the secure-payment strip under the
booking window with no code change:

    visa.svg          mastercard.svg          mtn-momo.svg          airtel-money.svg

Use the artwork each scheme supplies (Visa and Mastercard brand centres; MTN and Airtel
merchant kits) and keep to their usage terms — minimum size, clear space, no recolouring.
`.png` and `.webp` also work. Until a file exists the scheme shows as a text badge.
